資料備份 / 換手機

開了右上角的「雲端同步」就不用手動備份；這裡是額外留一份備份檔用的。

☁️ 雲端同步（存到你的 GitHub）

資料會存在你的私人 GitHub repo 裡，手機、電腦、阿瓜的手機都看同一份。

權杖只存在這台裝置。請用只開放「ning-data」一個 repo 的 fine-grained token。

☁️ 雲端同步中

資料 repo：

在另一台裝置（電腦、阿瓜的手機）打開設定連結，就會自動連上，不用再輸入權杖。連結裡有權杖，只傳給自己人喔。
