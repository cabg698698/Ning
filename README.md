# Ning ・ 我們的小本子

瓜甯 & 阿瓜 兩人專用的小工具，純前端網頁（HTML / CSS / JavaScript），不用安裝、不用後端。

## 功能

### 📅 行事曆
- 切換「瓜甯」、「阿瓜」、「兩人一起看」
- 一鍵模式：先選「💼 一般上班」或「🌙 值班」，再點日期就加上；再點一次同一天取消
- 「本月平日全設上班」快捷鍵，不會蓋掉已排的值班
- 兩人一起看時，兩人都沒排班的日子會用綠色標出來
- 每月統計上班、值班天數；左右滑動可換月份

### 📍 想去的地方
- 輸入店名或景點來搜尋定位（OpenStreetMap / Nominatim），也可以貼 Google 地圖的完整網址
- 自動判斷縣市，清單依縣市分組，地圖上用顏色區分
- 自動分類「🍜 美食」或「🏞️ 景點」，點分類標籤可以切換
- 「🧭 導航」一鍵開啟 Google 地圖導航
- 去過的地方可以打勾，預設隱藏

### 💾 記憶
資料存在瀏覽器的 localStorage，關掉網頁也不會消失。換手機時可以用頁面最下方的「匯出 / 匯入備份」。

## 使用
直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages。用手機開啟後選「加入主畫面」，用起來就像 App。
